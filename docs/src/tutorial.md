# Tutorial

This tutorial introduces GilaElectromagnetics through a set of short examples.
The examples can be downloaded as Julia scripts or Jupyter notebooks from the
`examples/tutorial` directory of the repository.

Gila solves electromagnetic problems in terms of currents. A vacuum Green's
operator maps currents to fields, while scattering operators compute the
currents generated by a material response. The impedance of free space is set to
`1` throughout this tutorial.

## Self Green's function

The simplest object in Gila is a vacuum Green's operator for a single volume.
The following code constructs an operator for an \(8\times8\times8\) region and
applies it to a random vector.

```julia
using GilaElectromagnetics

cells = (8, 8, 8)
scale = (1//32, 1//32, 1//32)

G = VacuumGreensOperator(cells, scale)

sources = rand(eltype(G), size(G, 2))
fields = G * sources
```

See `examples/tutorial/self_green.jl` or the notebook `self_green.ipynb` for the
complete script.

## Scattering from simple shapes

Scattering problems start from a plane wave. The initial current is
\(J_i = -i\,|k|\,\chi\,E_i\). The generated current is obtained with a
`ScatteringOperator`, and the scattered field is then computed with the vacuum
operator.

### Dielectric cube

```julia
using GilaElectromagnetics, StaticArrays
include("plot_utils.jl")

cells = (32, 32, 32)
scale = (1//32, 1//32, 1//32)
chi = fill(13.6 + 0.05im, cells)

kvec = SVector(1.0, 0.0, 0.0)
knorm = norm(kvec)

G0 = VacuumGreensOperator(cells, scale)
W = ScatteringOperator(cells, chi)

E_i(x,y,z) = exp(im * (kvec[1]*(x-1) + kvec[2]*(y-1) + kvec[3]*(z-1)))
Ei = [E_i(x,y,z) for x in 1:cells[1], y in 1:cells[2], z in 1:cells[3]]
J_i = -im*knorm .* chi .* Ei
J_g = W * reshape(J_i, :, 1)
E_s = im/knorm .* (G0 * J_g)
E_tot = reshape(E_s, cells) + Ei
```

The helper in `plot_utils.jl` can visualise a slice of the field.

## Dipole in a waveguide

A dipole is represented by a unit current at one grid point. The surrounding
waveguide is described by a susceptibility tensor. The total current is the sum
of the dipole current and the current generated by the scattering operator. The
field is then obtained from the vacuum operator.

```julia
using GilaElectromagnetics
include("plot_utils.jl")

cells = (64, 32, 32)
scale = (1//32, 1//32, 1//32)
chi = zeros(ComplexF64, cells)
for y in 12:20, z in 12:20, x in 1:cells[1]
    chi[x,y,z] = 1.5 + 0im
end

J = zeros(ComplexF64, prod(cells))
center = (32, 16, 16)
idx = (center[3]-1)*cells[1]*cells[2] + (center[2]-1)*cells[1] + center[1]
J[idx] = 1.0

G0 = VacuumGreensOperator(cells, scale)
W = ScatteringOperator(cells, chi)

J_tot = J + W * J
E_tot = im .* (G0 * J_tot)
E_tot = reshape(E_tot, cells)
```

A slice of the intensity illustrates the guided mode.

## External Green's function

Gila can also build operators between distinct volumes. The source and target
volumes must share the same scale.

```julia
using GilaElectromagnetics

src_cells = (8, 8, 8)
scale = (1//32, 1//32, 1//32)
src_orig = (0//1, 0//1, 0//1)
trg_orig = (1//1, 0//1, 0//1)

src_vol = GlaVol(src_cells, scale, src_orig)
trg_vol = GlaVol(src_cells, scale, trg_orig)

G_ext = VacuumGreensOperator(trg_vol, src_vol)
```

This operator couples sources in one region to fields in another.
